Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Fixed-length typed scalar storage and borrowed, zero-copy subviews.

Native Int and Float elements occupy eight bytes; Byte elements occupy one. Construction allocates the complete contiguous backing storage and initializes every element. Reads and writes check bounds. Buffers have one owner and no Copy method; views borrow that owner and cannot outlive it. Storage never grows. Scalar reads and writes lower to checked indexing in both executable backends. These are Foster scalar layouts, not arbitrary C record or pointer layouts.

Provided types

Bufferpublic

A uniquely owned, fixed-length typed allocation. Construct with integers, floats, or bytes. Scope exit releases storage. Borrowed elements and views retain the owner's lifetime; no raw address escapes.

Required methods

  • length
    Returns the number of initialized elements.
  • read
    Copies the scalar at index. Fails unless 0 <= index < length(). Lowers directly to checked indexing without generic Copy dispatch.

Functions and methods

  • borrow
    Borrows one initialized element; invalid indexes return None.
  • length
    Returns the number of initialized elements.
  • read
    Copies the scalar at index. Fails unless 0 <= index < length().
  • view
    Borrows the half-open range [start, end), without copying its elements.
  • write
    Replaces the element at index without allocating or changing length.

BufferViewpublic

A bounded, zero-copy view whose Storage reference retains the buffer lifetime. Indexes are relative to the view. Writes update the owner in place.

Functions and methods

  • borrow
    Borrows an element relative to the view; invalid indexes return None.
  • length
    Returns the number of elements visible through this view.
  • read
    Copies one element. Asserts unless 0 <= index < length().
  • write
    Replaces one element in the owner without resizing its allocation.
